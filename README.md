# Веб-приложение

**main.py** — HTTP-сервер на стандартной библиотеке Python: GET/HEAD отдают страницы по маршрутам (`/`, `/catalog`, `/category`, `/contacts`) из `pages.html` с `Content-Type: text/html`, POST на `/contacts` обрабатывает форму и печатает данные в консоль, для 404/500 и неподдерживаемых методов отдаются соответствующие секции из того же файла.

**pages.html** — один HTML-файл с секциями (`home`, `catalog`, `category`, `contacts`, `err404`, `err500`): вёрстка на Bootstrap с CDN, страницы каталога и категории, форма обратной связи и страницы ошибок.

## Как проверить

1. `python main.py`
2. В браузере проверить маршруты:
   - http://127.0.0.1:8000/
   - http://127.0.0.1:8000/catalog
   - http://127.0.0.1:8000/category
   - http://127.0.0.1:8000/contacts
3. Отправить форму на странице «Контакты» — в терминале появляется вывод POST.
4. Например `curl -X PUT http://127.0.0.1:8000/` — ответ 404 с пользовательской страницей.
